# AI 前沿与智能硬件周报

每周一北京时间 08:00 整理上一完整自然周（周一至周日）的公开资讯。四个栏目：AI 前沿技术、智能硬件行业、智能家居、AI 开源热点项目。每期约 10–20 个主题，同类动态可合并，只写可核实的新闻事实和原文链接，不加个人化建议。

## 目录

| 路径 | 用途 |

## 交付分工

小D负责收集、核实、去重和成稿。接入后，Hermes 从本仓库读取正式周报，负责写入飞书多维表格、发布群卡片，并基于已发布的资讯回答群内提问。仓库不运行采集或推送任务。

**交付与归档：** 周报仍在 ChatGPT 私聊交付，公开版归档在 `weekly/`，首期见 [2026-11-16 至 2026-11-22](weekly/2026-11-23.json)。Hermes 拉取和飞书分发尚未联通。仓库仅存放可公开的资讯与文档。
